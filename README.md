# Skate Lab 🛹

רשת חברתית לסקייטבורד: מאמנים מעלים סרטוני הדרכה, רוכבים שואלים שאלות ומעלים
טריקים לפידבק.

## הרצה

```bash
cd server && npm install && npm start
```

ואז לפתוח <http://localhost:3000>. דורש Node 20 ומעלה (משתמש ב-SQLite המובנה
של Node). התלות היחידה היא Express — אין שלב build בצד-לקוח.

כדי להראות את זה למישהו בטלפון על אותה רשת, מוצאים את כתובת ה-IP של המחשב
(`ipconfig getifaddr en0`) ופותחים `http://<כתובת>:3000`.

## מה קיים

- **חשבונות אמיתיים** — הרשמה עם סיסמה, כניסה, יציאה ומחיקת חשבון
- **פיד משותף** — כולם רואים את מה שכולם מעלים, עם סינון לפי סוג
  (שיעורים / טריקים לפידבק) ולפי אזור
- **אנשים** — ספריית כל הקהילה: מאמנים, תלמידים וסקייטרים, עם סינון לפי
  תפקיד, אזור, סגנון וחיפוש חופשי
- **מועדפים** — סימון מאמנים, כדי לראות בפיד רק את הסרטונים שלהם
- **העלאת סרטונים** עם קובץ וידאו אמיתי, תמונה ממוזערת (או אימוג׳י), כותרת,
  אזור, רמה וסגנון
- **שאלות ופידבק** — תגובות מקוננות על כל סרטון. על שיעור זו שאלה למאמן,
  על טריק זה פידבק לרוכב, ובעל הסרטון עונה בשרשור מתחת
- **תיבת התגובות** — בעל הסרטון רואה את כל מה שנכתב לו, עם סימון מה עדיין
  מחכה לתשובה ומונה על הלשונית
- **התיק** — דף שמראה אילו טריקים נחתת. שם הטריק חופשי (אין רשימה סגורה),
  וכל טריק **חייב סרטון** — הסרטון הוא ההוכחה
- **הישגים** — **הישג לכל טריק בנפרד**: קיקפליפ, אוליי, טרה פליפ. 266
  הישגים, אחד לכל טריק בקטלוג. ההישג נפתח כשהטריק נכנס לתיק, כלומר עם
  סרטון שמוכיח אותו. אין הישגים על צפיות, לייקים או עוקבים
- **עוזר AI** — לשונית 🤖 עם צ׳אט מתמשך (השיחה נשמרת), שאלות טכניקה
  לרוכבים וטיוטת פידבק למאמנים
- **לייקים** על כל סרטון
- **בקשות חברות וצ׳אט** בין כל שני משתמשים — לא רק מול מאמנים
- **הסרטונים שלי** — העלאה וסטטיסטיקה (צפיות, לייקים, פידבק)

## החלטות שכדאי להכיר

- **סיסמאות** נשמרות כ-scrypt עם מלח אקראי לכל משתמש, וההשוואה בזמן קבוע.
  הסשן הוא עוגיית `HttpOnly`, כך שאין טוקן שמסתובב ב-JavaScript.
- **המונים מחושבים בשאילתה** ולא נשמרים בטבלה (סרטונים, עוקבים, תשובות).
  זה מונע מצב שבו מונה נסחף ומציג מספר שקרי.
- **מחיקת חשבון דורשת סיסמה מחדש**, ומוחקת בשרשור את הסרטונים, הקבצים,
  התגובות, הלייקים, הבקשות והצ׳אטים.
- **קבצים** יושבים ב-`server/uploads/` ומוגשים מ-`/media` עם תמיכה ב-Range,
  כדי שאפשר יהיה לדלג באמצע סרטון.
- **תמונות ממוזערות מוקטנות בצד-לקוח** ל-720px ול-JPEG לפני ההעלאה.
- **6 מאמני דמו ו-12 שיעורים** נזרעים בהפעלה הראשונה. הם מסומנים "דוגמה"
  ואין מאחוריהם קובץ וידאו. מאמן דמו מאשר בקשת חברות מיד ושולח הודעת פתיחה,
  כדי שאפשר יהיה לראות את הזרימה בלי משתמש שני.
- **המונחים והפארקים אמיתיים** — שמות הפארקים נלקחו מסקייטפארקים קיימים
  בישראל (גלית בתל אביב, הכט בחיפה, גן סאקר בירושלים, הרצליה, כרמיאל,
  באר שבע), ושמות הטריקים נכתבים כמקובל בקהילה: אוליי, מניואל, פופ שאביט,
  קיקפליפ, גריינד, דרופ-אין, פאמפינג, קופינג, קארב.
- **אין אישור הורים** — לפי החלטה מכוונת. תאריך הלידה נשמר והגיל מחושב,
  אז אפשר להוסיף בהמשך. לפני עלייה לאוויר עם קטינים זה יידרש (COPPA/GDPR-K).

## ה-AI

העוזר משתמש ב-Claude API. כדי להפעיל אותו:

```bash
export ANTHROPIC_API_KEY=...
cd server && npm start
```

בלי המפתח האפליקציה עובדת רגיל, ובמקום העוזר מוצגת הודעה. ה-AI עונה על
שאלות טכניקה ומנסח טיוטת פידבק — הוא **לא** קובע אם טריק נחת ולא מפרסם
דבר בעצמו.

## איך התיק מונע רמאויות

ארבע שכבות, מהחזקה לחלשה:

1. **סרטון חובה** — אי אפשר להוסיף טריק בלי סרטון משלכם עם קובץ אמיתי,
   ואי אפשר לצרף את אותו סרטון לשני טריקים.
2. **טביעת אצבע לקובץ** — כל קובץ וידאו מקבל SHA-256. אם מישהו מעלה קובץ
   שכבר הועלה קודם על ידי אחר, הוא מסומן 🚩 עם שם המעלה המקורי. זה בדיוק
   מה ש-AI לא יכול לתפוס.
3. **בדיקת AI** — הדפדפן מחלץ 6 פריימים מהסרטון ושולח אותם למודל ראייה,
   שמעריך אם הרוכב סיים על הלוח או נפל.
4. **אימות מאמן** — ✓ אנושי, הדרגה הגבוהה ביותר, וגובר על כל השאר.

**מה שהשכבות האלה עדיין לא תופסות:** ה-AI לא מבחין בין קיקפליפ להילפליפ,
אז מי שיכתוב שם של טריק קשה ויצרף סרטון של טריק קל — יעבור. סימון הכפילות
תופס רק קובץ זהה בייטית, לא צילום מחדש של מסך. לכן הדירוג מוצג תמיד
בגלוי על הכרטיס, ואף פעם לא מוסתר.

## קטלוג הטריקים וההישגים

`server/tricks.js` (וגיבוי ב-`tricks.json`) שומר 352 רשומות — 266 טריקי
בסיס, 86 מהם עם פרונטסייד ובקסייד — בשמונה דיסציפלינות, עם שם עברי ולועזי,
רמה ותיאור.

**כל טריק בסיס הוא הישג.** ההישג נפתח כשטריק בשם הזה נכנס לתיק.
שם הטריק בתיק הוא טקסט חופשי, ולכן ההתאמה גמישה: אותיות קטנות/גדולות,
רווחים, מקפים וקידומות פרונטסייד/בקסייד מנוטרלים לפני ההשוואה, וכל טריק
מזוהה גם בשמו העברי וגם באנגלי. כך "קיקפליפ", "Kickflip", "kick flip"
ו-"קיק פליפ" פותחים את אותו הישג. טריק שלא זוהה בקטלוג נשמר בתיק כרגיל,
הוא פשוט לא פותח הישג עם שם — והוא מוצג בנפרד מתחת לרשימה.

## עלייה לאוויר (Render)

`render.yaml` מגדיר את הכל. מה שצריך לעשות פעם אחת:

1. להעלות את התיקייה ל-GitHub (`.gitignore` כבר מוציא את `.env`, את
   המסד ואת ההעלאות).
2. ב-Render: **New → Blueprint**, לבחור את המאגר. הוא קורא את `render.yaml`.
3. למלא שני ערכים שלא נשמרים ב-git:
   - `INVITE_CODE` — הקוד שבלעדיו אי אפשר להירשם. אתם מחלקים אותו.
   - `ANTHROPIC_API_KEY` — רק אם רוצים את ה-AI.
4. Deploy. הכתובת תהיה `https://skate-lab.onrender.com` (או השם שתבחרו).

**הדיסק הקבוע חובה.** `DATA_DIR=/var/data` מצביע על דיסק שנשמר בין
דיפלויים; בלעדיו כל עדכון קוד היה מוחק את המשתמשים ואת הסרטונים.
הדיסק דורש תוכנית בתשלום (`plan: starter`).

### מי יכול להיכנס

הקישור פתוח, אבל ההרשמה סגורה מאחורי `INVITE_CODE` — מי שאין לו את הקוד
רואה את מסך הפתיחה ולא יכול ליצור חשבון. לשינוי הקוד: לעדכן את משתנה
הסביבה ב-Render. חשבונות שכבר נרשמו לא מושפעים.

### הגנות שפועלות בייצור

| הגנה | ערך | איפה |
| --- | --- | --- |
| קוד הזמנה | `INVITE_CODE` | `server/guard.js` |
| הגבלת הרשמות | 5 לשעה מכתובת IP | `POST /api/auth/register` |
| הגבלת התחברויות | 10 לרבע שעה מכתובת IP | `POST /api/auth/login` |
| מכסת AI | 20 לשעה, 100 ליום למשתמש | `needsAi` |
| גודל העלאה | `MAX_UPLOAD`, ברירת מחדל 60mb | `server/server.js` |
| עוגיית סשן | `Secure` כש-`NODE_ENV=production` | `server/auth.js` |
| תיקיית השרת | חסומה מהגשה סטטית | `server/server.js` |

הגבלת הקצב יושבת בזיכרון ומתאפסת בהפעלה מחדש. היא עוצרת הצפה אוטומטית,
לא תוקף שמחליף כתובות — לכן קוד ההזמנה הוא ההגנה העיקרית ולא היא.
